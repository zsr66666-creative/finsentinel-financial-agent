- Q02“资产规模/股东权益”：BM25 Top-10未找到总资产和归母净资产；向量/RRF仍漏总资产。词面/同义表达是待验证原因，不能仅凭结果认定唯一根因。

- Q11：BM25 Top-10全部必要证据命中，RRF仍漏收入。融合不是单向收益。
- 其余逐题缺失ID、Top-10及具体分母见结果JSON。不在本轮反馈上修改分词、阈值或权重后冒充同一冻结实验。
