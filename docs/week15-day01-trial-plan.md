# 第十五周 Day 1：用户试用与错误分析方案

## 目标

通过 2–3 位真实用户完成相似难度的财报检索与证据复核任务，记录完成时间、步骤数和错误类型，修复一个最高频问题并做回归。

## 任务包

每位参与者完成：

1. 查找一家公司的年度营业收入或净利润；
2. 找到对应 PDF 页码和来源；
3. 查看一条告警并判断是否需要人工复核；
4. 提交确认、驳回或修改反馈。

## 记录指标

- 找到答案耗时；
- 找到证据耗时；
- 页面操作步骤数；
- 是否完成；
- 错误分类：数据、计算、检索、引用、期间、交互；
- 用户主观阻塞点。

真实参与者、时间和结果必须在试用后填写，开发者自测不计为用户试用。
