# 明确问句到本地 chunk 的比较验收

已实现独立、可拒绝的明确问句解析：立讯精密 + 明确日期 + 母公司/合并 + 应收账款 + 对比日期 + 是否增加/未增加。缺少口径、未知公司、无效/倒序日期、多重否定、预测或不符合完整语法的问题返回 needs_review，不使用模糊关键词猜测。

对已人工复核的特定 PDF，完整页提取的应收账款行通过文件 SHA256、物理页码、指标及两列数值与现有本地 spans 精确唯一匹配：

| 口径 | 本地 chunk ID |
| --- | --- |
| 合并 | 002475-2026H1-p60-s20 |
| 母公司 | 002475-2026H1-p63-s4 |

本地 4/4 明确问句到 chunk 比较验收通过；正向“增加”为 false，显式否定“未增加”为 true。查询解析和对齐的 8 项单元测试覆盖拒绝情形。结果见 `data/evals/week04-query-alignment.json`。

复现（PYTHONPATH=backend;.，私有 PDF 不入库）：

```text
python -m scripts.week04_query_alignment_check --pdf <PDF路径> --output data/evals/week04-query-alignment.json
```

边界：本地 span ID 与数据库设计使用相同命名规则，但本次未连接阿里云数据库，不能宣称数据库已存在这些 ID。母公司标题来自新增完整页核验，仍以独立审计定位返回，没有伪造标题 chunk。日期和单位取自该 PDF 已复核契约；解析器可识别其他合法日期，但验收脚本仅接受该契约日期。不是通用自然语言系统，也未接入线上 API。

后续远端步骤：以只读查询核对两个 chunk ID 的 provenance、原文哈希及源文件哈希；如缺失，补齐真实语料和标题来源后再进行导入与读回验收。数据库存在性核验通过前，不扩大线上声明。
