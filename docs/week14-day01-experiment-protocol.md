# 第十四周 Day 1：Agent 对照实验协议

日期：2026-11-07

## 实验目标

在相同问题集、语料版本、模型配置、工具白名单和超时预算下，比较确定性工具基线、单 Agent 和双 Agent 工作流。实验只回答双 Agent 是否减少数字或引用错误，以及增加多少延迟和调用成本。

## 冻结条件

- 评测集：`data/evals/golden_questions.jsonl`，74 条，其中 59 条可评分；SHA-256 记录在实验清单。
- 语料：`week10-multi-company-v3`。
- 检索：BM25 + 查询扩展；真实 embedding 固定为 `BAAI/bge-small-zh-v1.5`，512 维。
- 模型和 Prompt：`deterministic-demo-v1`、`evidence-v1`，temperature 0。
- 工具预算：分析最多 6 次，复核最多 3 次，最多 1 轮修订。
- 超时：单题 60 秒；超时计入失败率和延迟分布。
- 测试集只在协议冻结后运行，不用于调参。

## 三组条件

1. **确定性基线**：只调用白名单结构化工具和检索，不生成 Agent 自由结论。
2. **单 Agent**：一个分析 Agent 完成问题解析、检索、计算、证据引用和结构化输出。
3. **双 Agent**：分析 Agent 先输出，独立复核 Agent 检查数字、期间、引用支持程度；最多一轮修订，仍不充分则 `needs_review`。

## 指标和报告要求

每组记录命中数/总数：数值正确率、引用覆盖率、正确拒答率、工具成功率、Recall@5、p50/p95、超时率和成本；同时记录运行时间、代码版本、数据集划分和失败原因。

## 禁止事项

不在测试集上调 Prompt、阈值或检索配置；不把检索 Recall 直接当作 Agent 质量；不把目标值写成实测值；不把合成 fixture 或 `needs_review` 当作正确答案。
