# 管理员创建的真实账号

本阶段把浏览器演示登录替换为 PostgreSQL 账号和服务器会话。部署前先确认
`https://120.24.108.60/` 可正常访问且无证书警告。首个管理员在阿里云控制台创建，
没有默认账号、默认密码、开放注册、短信或邮件费用。

## 角色

| 角色 | 能力 |
| --- | --- |
| viewer | 研究、原文检索、比较、报告读取/导出、管理本人资料 |
| reviewer | viewer 能力及财务复核、告警反馈 |
| admin | reviewer 能力及账号管理、后台评估和采集管理 |

权限由后端验证；修改浏览器资料或直接调用接口不能提升权限。账号禁用、密码重置、
改密码和权限变更会撤销旧会话。最后一个有效管理员不能被禁用或降级。
首次登录使用管理员交付的临时密码，必须先修改密码，再进入研究台。

账号管理页面为 `/admin/users`。普通用户看不到管理入口，直接调用返回403。
管理员可创建账号、调整角色、禁用和重置密码。请通过受信渠道交付临时密码，
不要在仓库、命令行参数、截图、运行日志或聊天中发送密码。

## 部署

执行发布时提供的 SHA256 校验和完整安装命令。上传包为已提交源码，不含账号、
私钥、Cookie、报告PDF、模型或生产数据库。安装仍需要 npm/PyPI 网络访问。

安装器先校验服务布局、HTTPS、包清单，预构建前端并执行测试，然后备份数据库及
旧服务配置，执行增量迁移006及隔离PostgreSQL验收。在切换之前提示输入首个管理员用户名、昵称和密码；
密码输入不回显。已有有效管理员时跳过初始化，不重置其密码。

生产后端通过独立 systemd drop-in 指向本次保留源码，并设置：

```ini
Environment="AUTH_ENABLED=true"
Environment="AUTH_ORIGIN=https://120.24.108.60"
Environment="AUTH_COOKIE_SECURE=true"
```

初始应用配置、证据语料、向量和财务复核记录不清空。保留HTTPS站点及证书，
HTTP应用入口改为308跳转HTTPS，ACME挑战路径例外保留并重新执行模拟续期。
只允许同源HTTPS提交账号信息。8000、8081继续只监听本机。
保留80用于证书续期，443用于真实登录。Nginx变更也包含在失败回退中。

若后端/前端切换或冒烟失败，安装器恢复先前服务配置及前端构建。增量账号表和
已创建账号保留用于排查，不自动恢复整个数据库，以免丢失同时产生的业务数据。
回退旧版本会恢复旧版本的演示登录和访问规则，应尽快排查后重新升级。

## 用户验收

1. 打开HTTPS登录页：错误密码被拒绝；初始管理员正确密码可登录。
2. 按提示修改临时密码，再用新密码登录；旧密码不能登录。
3. 管理员新建 viewer、reviewer，分别用浏览器隐私窗口验证权限。
4. viewer 可检索、比较、导出，但不能提交复核或调用用户管理API。
5. reviewer 可提交真实人工意见；记录绑定服务器用户ID和署名快照。
6. 禁用测试账号后其旧会话失效；昵称头像在另一浏览器登录后保持一致。
7. 退出后返回登录；刷新或直接请求受保护API不能继续读取数据。
8. 首页、公司页、比较、导出、深浅色及移动端保持正常，静态资源没有404。

不把自动测试写入视为真实人工复核。历史自报署名保留，并与新认证用户记录区分；
不会根据重名昵称自动认领历史。真实账号证明的是当前系统登录身份，不代表金融
专业资质，也不使应用追加历史成为外部防篡改审计账本。

## 运维与恢复

管理CLI通过服务器上的当前保留源码运行，数据库连接沿用本机 PostgreSQL。
正常情况下在网页里重置其他用户的密码。如果唯一管理员忘记密码，维护者应在
服务器控制台使用账号CLI的恢复入口；不提供未经认证的公网找回密码接口。
恢复命令需在当前部署保留源码中运行，例如：

```bash
sudo -u finsentinel env \
  PYTHONPATH=/opt/finsentinel-releases/你的账号版本目录/backend:/opt/finsentinel-releases/你的账号版本目录 \
  DATABASE_URL='postgresql+psycopg:///finsentinel?host=/var/run/postgresql' \
  /opt/finsentinel/.venv/bin/python -m scripts.manage_accounts reset-admin
```

替换为安装输出的保留目录；用户名和新临时密码均交互输入。该入口仅用于可信服务器控制台，
恢复已有管理员、启用账号并撤销其旧会话，不是公开找回密码服务。

认证响应禁止缓存；会话Cookie使用 Secure/HttpOnly/SameSite 和服务器撤销记录，
浏览器 localStorage 中的旧演示资料不是登录凭据。初始会话绝对有效期8小时，
过期后重新登录。开启账号模式后认证故障返回503，不回退为匿名管理员。

部署报告分别列出本地测试、Linux CI、服务器迁移及隔离PostgreSQL检查、受信TLS
冒烟、浏览器角色验收。尚未获得服务器输出的项目不标为已上线通过。
