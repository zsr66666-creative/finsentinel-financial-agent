# Week 4：精确指标行开发实验

日期：2026-11-11。新版本实验，原协议、结果及生产检索不变。

## 原因验证

单独查询“应收账款”时，应收分保账款、应收款项融资及坏账损失排在目标合并资产负债表行之前；查询“存货”时，“项目/期末余额/期初余额”表头与含“价值”的会计政策描述排在正确数值行之前。来自其他表格的同名行也会形成竞争。

目标Q09的原文锚点固定为002475-2026H1的p8-s5、p60-s20、p60-s30。它们已存在于语料，问题不是缺文档，而是原词法扩展和排序。

## 实验设计

实现：`backend/app/exact_metric_experiment.py`；运行：`python -m scripts.week04_exact_metric_eval`。

沿用上一版通用指标别名识别。对每个请求指标，优先取完整数值行名匹配的片段，而非仅包含部分词。PDF换行空白和括号单位在匹配时归一化。同页出现“合并资产负债表”的片段优先，再按ID稳定排序，多指标轮流分配候选位置；不足时保留词法候选。

同页标题是实验性的上下文信号，不是完整报表口径解析。未从稀疏提取页间继承“合并/母公司”状态，也不把没有标题的页面判定为母公司。其他报表、续页和OCR格式仍需新样本验证，不能承诺所有口径正确。

候选排名不读黄金ID、答案值、case ID或固定页码。公司、期间、负例证据包过滤与原16题相同。因规则由已知开发错误启发，仍属于开发集调优。
