# 报告阅读与证据定位

## 阅读入口
原文检索、证据比较、公司财务核对、证据收藏与报告库提供原文阅读入口。阅读页并列显示服务器解析的证据片段、物理页码和文件SHA256；浏览器原生PDF阅读器打开相应页。物理页码按文件从1开始，可能不同于报告印刷页码。

提供上一页、下一页、指定物理页和独立打开PDF。不同浏览器对内嵌PDF及#page的支持不同，移动设备可使用独立打开。首版不承诺自动文字高亮。PDF为完整原文件，不表示系统已全文索引，也不表示原文经过人工复核。

## 来源及权限
只有已登录账号可以读取元数据或PDF。服务器从已登记的证据来源或固定财务契约确定PDF哈希；不接受客户端文件路径，不在线抓取任意URL。PDF只从受控本地目录读取，核验SHA256与页数，缺失、哈希不符、页码越界或来源不明确均明确报错。收藏链接绑定保存时哈希，来源变化时不会悄悄跳到其他文件。

同源cookie保护PDF；支持单段HTTP Range与HEAD，响应private,no-store，不公开永久文件地址。原始路径及内部异常不会返回浏览器。不新增数据库表或第三方PDF渲染依赖。

## 部署与验收
源码离线包构建后切换，先调用现有备份及隔离恢复验证，保留账号、私人研究记录、证据向量、TLS与定时任务。切换失败恢复旧前后端配置；不回滚整个生产库。

服务验收包含匿名元数据/PDF请求拒绝、HTTPS页面与静态资源检查。浏览器需登录后分别从检索结果、公司核对、收藏和报告库打开PDF，核对物理页数与摘录；验证页码切换、独立打开和移动布局。CI使用实际生成PDF验证哈希、来源与范围请求，不能代替服务器真实文件或浏览器阅读验收。
