# 暗夜主题与公司详情页实施计划

已批准范围：三态主题、独立公司详情、现有数据契约、默认阿里云部署。行业扩容后续单独进行。

1. 测试先行：主题合法值与系统偏好解析；公司链接与登录返回地址拒绝外部地址；公司范围过滤。
2. theme.mjs + theme-provider.tsx：首次绘制前设置主题，监听系统偏好和跨标签存储，存储禁用仍可切换；设置页及全站固定控件可用。
3. globals.css：完整深色语义令牌，保留暖茶侧栏，检查文字及控件对比，移动布局。
4. /companies/[companyId]：动态路由客户端读取既有公司、指标和告警 API；报告期筛选、证据标识、加载/错误/404/空态，不伪造真实数据。公司列表卡片链接跳转；登录返回保留安全公司路径。
5. node tests、tsc、生产构建、可用浏览器验收；推送固定修订部署脚本，沿用登录壳探测、静态资源同步、回退。服务器执行及浏览器人工验收单独记录。
