# Google Drive 异地备份设计

## 目标

在现有阿里云 ECS 本地备份和每周隔离恢复检查之外，增加到用户 Google Drive 免费可用空间的异地副本。Google Drive 只接收密文；不购买存储、不公开分享备份，也不把生产文件、OAuth token 或解密私钥放入 Git、网页或聊天。

## 方案

沿用 `scripts.operations_backup` 生成并验证的恢复点目录。恢复点通过 `tar` 生成单一流，使用 `age` 的用户公钥加密，再由 `rclone` 通过 Google Drive API 上传到专用目录。每个对象使用严格格式的唯一 UTC 时间戳和随机 ID 命名。服务器只保存 age 公钥、root-only 的 rclone OAuth 配置和远端目录设置；age 私钥仅保存在用户自己的 Windows 电脑和独立离线备份介质。

上传流程在当前本地恢复点完成完整性检查后执行：先检查 Google Drive 可用额度；上传到专用临时对象；回读对象并比较密文 SHA-256；校验成功后将临时对象改为正式名称，再执行远端保留清理。只处理本工具严格命名且位于专用目录中的对象。保留最近 7 个已校验远端副本；若新对象上传或回读验证失败，不删除旧对象、不删除本机恢复点，任务报告失败。

保持现有每日本机备份和每周隔离恢复机制。远端上传启用前为显式配置；没有 OAuth 配置、公钥或足够免费空间时，不启动远端写入，不静默退化为明文上传。专用状态只记录成功时间、恢复点 ID、密文哈希和结果码，不暴露 OAuth token、备份清单或文件名之外的敏感元数据。

## Google Drive 授权与密钥

用户在本机生成 age 密钥对，将公开 recipient 配置到 ECS；私钥和恢复说明在本机离线保管。用户通过自己的 Google 账号在本地完成 rclone OAuth 授权，再从阿里云控制台交互配置服务器端 token；token 文件 root-only，命令行参数、shell history、服务日志和报告均不得含 token。仓库和聊天仅传输无密钥部署包与公开校验和。

使用专用 Drive 目录。部署时先通过 Drive API 查询剩余配额，并以当前一个恢复点大小估算至少可同时容纳 8 份（7 个保留点加待验证的新点）；低于该容量或 Drive 配额未知时拒绝启用，不提前删除有效旧点，也不购买配额。实际账号可用空间受其 Gmail/Drive 其他数据占用影响，免费容量不作保证。

## 恢复与验证

上传后服务器下载密文回读并核对 SHA-256，证明远端对象字节完整；服务器不持有 age 私钥，不能假称在 ECS 完成了解密恢复。用户在 Windows 端使用私钥定期下载和解密一份远端样本，校验内部 `COMPLETE`、manifest、数据库 dump 和所有源文件 SHA-256。灾难恢复时将加密对象安全传到新 ECS，在受控维护窗口短暂提供私钥完成解密，随后立即删除服务器上的私钥副本，并按现有隔离恢复流程先恢复到临时数据库；确认后再执行单独的生产恢复流程。禁止覆盖生产库作为自动验收的一部分。

## 失败处理与保留

- 本机备份失败时不尝试远端上传。
- 远端认证、额度、网络、加密、上传、回读哈希或清理失败均记录有限错误码并使 offsite 任务失败；不得记录命令原始 stderr 或 OAuth 内容。
- 上传成功但回读失败时保留临时对象供排查，不将其计入 7 个成功副本，也不清理已有有效副本。
- 删除旧远端对象前重新检查专用目录、对象名格式、对象数和新对象验证状态；未知对象永不自动删除。
- Google 免费空间不足时保持本地备份运行并显式显示异地副本过期/失败；不自动购买容量、不减少保留数、不删除本机备份。

## 验收

1. 自动化测试覆盖加密前后数据不可直接读取、严格对象名、回读哈希失败、quota不足、OAuth缺失、命令超时/失败、保留边界、仅清理自管对象和不泄露 token。
2. Linux 安装验收证明本机旧备份/隔离恢复未回归；首次同步一个既有完整恢复点，上传回读哈希成功。
3. Windows 私钥可下载并解密远端对象，内部 manifest 和所有文件哈希验证通过。
4. 连续生成超过 7 个远端恢复点后，远端只保留 7 个已验证对象；注入失败时旧对象数不减少。
5. 管理员运维页分别显示本机备份和远端备份的最近成功/失败时间；未配置远端时明确显示 `not_configured`。
6. 正式启用前检查 Drive 免费可用配额足以支持临时第 8 份上传；未达容量要求则停止部署，不削减策略。

## 明确限制

本方案降低 ECS 磁盘/整机故障造成的数据丢失风险，但依赖用户妥善保管 age 私钥和 Google 账号；不会防止已获授权的 Google 账号或 OAuth token 主动删除文件。免费容量和 Google API 可用性由提供商决定。真实财务复核仍必须由有权限的人检查来源并提交，备份实现不能代替人工判断。
