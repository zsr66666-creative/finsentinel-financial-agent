# Report reader and evidence location

User approved implement reading source PDF pages from search, compare and saved evidence; default ECS deployment. First version independent /reader page with source evidence side panel and native browser PDF iframe, physical page navigation and open-original fallback. No pdf.js/CDN/new dependencies or highlight claims.

## Backend contract
Authenticated-only GET /api/v1/evidence/reader?chunk_id=... OR company_code+period+document_sha256 with optional page integer. chunk locator must resolve exact persisted embedding provenance or reviewed comparison contract anchor; client-supplied file paths/URLs never read. GET /api/v1/evidence/documents/{sha256}/pdf serves same-origin application/pdf inline from ingestion blob root (default /var/lib/finsentinel/ingestion/blobs) or explicit known legacy source dir. Only registered SHA in indexed provenance or known reviewed contracts; verify SHA bytes and parse page_count via installed PyMuPDF before response. Reject symlinks and path escapes, encrypted/unreadable PDF, invalid page, missing locator; don't fetch external URLs. Hash bytes actually served (no file replace race), bounded PDF size <=100MiB. Cookie authentication required even AUTH_ENABLED=false, existing middleware protects. Cache-Control private,no-store, nosniff; safe filename hash.pdf. Support GET single HTTP Range including suffix/open ended and HEAD for native reader; 206 exact content, 416 correct Content-Range; malformed/multirange explicit416; Range should avoid full multi-client duplication where practical at1.7GB RAM. Don't expose local paths, credentials or raw exceptions. No schema changes.

Metadata response {document_sha256,document_id,company_code,period,page,page_count,text,source_status,source_url,pdf_url}. pdf_url canonical internal route; text from server, source_url displayed as text, never used as arbitrary redirect. page from chunk or explicit page; server validates <=page_count. Page request with only sha and page may resolve matching registered document for report library. Ambiguous document identity fails closed. Reader shows that PDF fullfile != full indexed coverage; historical favorite source should bind PDF hash rather than current chunk silently changing document.

## UI
Reusable safe readerHref locator helper encodes chunk_id plus expected document_sha256 when known; backend rejects hash mismatch rather than opening changed document. Direct sha/page+company+period for contract anchors or saved snapshot. /reader?chunk_id=...&document_sha256=... or /reader?company=...&period=...&sha=...&page=... . Authenticated fetch metadata first, show source excerpt/page count/hash and iframe internal pdf_url#page=N; page controls integer clamp explicit. Newtab same-origin fallback and PDF download optional. Reader links in evidence-search result, company verified financial evidence, legacy compare result, saved evidence and report library where metadata present. Only render links for complete safe locators. Native PDF rendering/pagefragment varies browser; fallback newtab link. Explicit loading,error,missing,state; mobile stacked, existing dark/theme/focus. Account change aborts metadata and clears private display. Never auto fetch external source URL.
