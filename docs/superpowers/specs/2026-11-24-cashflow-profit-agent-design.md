# 经营现金流与净利润背离分析设计

## 目标

为 TCL 科技、中联重科、徐工机械、柳工和京东方五家试点公司，建立一条可审计的金融 Agent 分析闭环：从年报证据提取已核验的净利润和经营活动现金流净额，使用确定性金融公式计算同比变化与现金流利润比，生成可追溯图表，并输出规则约束的结构化结论。

## 范围

第一阶段只处理“经营现金流与净利润是否背离”这一问题。支持相邻年度比较和年度趋势展示。输入数据必须包含公司代码、报告期、指标名称、数值、单位、合并报表口径、文档 SHA256、PDF 物理页码、原文片段和提取状态。只有 `human_verified` 数据进入正式结论。

## 公式

```text
净利润同比率 = (本期归母净利润 - 上期归母净利润) / abs(上期归母净利润) × 100%
经营现金流同比率 = (本期经营活动现金流净额 - 上期经营活动现金流净额) / abs(上期经营活动现金流净额) × 100%
现金流利润比 = 经营活动现金流净额 / 归母净利润
```

所有计算使用 Decimal。上期值为零、单位不一致、报表口径不一致或输入缺失时，返回 `needs_review`，不得补值或生成确定性结论。

## 背离规则

| 条件 | 结论类型 |
| --- | --- |
| 净利润同比 >= 0 且现金流同比 >= 0 | 同步改善 |
| 净利润同比 < 0 且现金流同比 < 0 | 同步恶化 |
| 净利润同比 >= 0 且现金流同比 < 0 | 利润增长但现金流恶化 |
| 净利润同比 < 0 且现金流同比 >= 0 | 利润恶化但现金流改善 |
| 数据不足或口径冲突 | 无法判断 / 需复核 |

每个派生结果保存公式、输入指标 ID、证据 ID 和证据页码。

## 图表

后端输出两类图表数据：净利润同比率与经营现金流同比率的对比图，以及现金流利润比年度趋势图。缺失年度保留为空，不插补。图表响应包含公司、报告期、单位、数据来源页码和计算状态；前端只渲染后端结果。

## Agent 边界

Agent 负责识别问题、选择白名单指标和公式、组织解释。确定性工具负责检索、计算、判定和图表数据生成。复核器检查公司、报告期、合并口径、单位、公式、输入值和页码。输入缺失或冲突时降级为 `needs_review`。

## 验收

五家公司各至少验收一组相邻年度。验收必须证明：Decimal 复算一致；公式、输入值、单位和页码可展开；图表值与接口值一致；结论类型符合规则；缺失或冲突数据进入复核；输出不含无来源数字。只有全部通过后，页面才显示财务计算和结构化结论已完成。
