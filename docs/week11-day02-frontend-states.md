# Week 11 Day 2：前端连接状态与刷新交互

## 完成内容

- 将首页数据加载抽为可复用的 `loadDashboard`，同时支持首次加载和手动刷新。
- 增加 `loadError` 与 `refreshing` 状态，连接失败时明确展示接口错误，并保留离线演示数据。
- 在数据服务 banner 和错误提示中提供“刷新数据/刷新中…”交互，避免把失败刷新显示成成功。
- 增加连接状态和刷新按钮文案的纯函数回归测试。

## 验证

- `frontend/npm test`：6 passed。
- `frontend/npm run build`：成功，Next.js 静态构建完成。

## 边界

离线模式仍使用合成 fixture 数据，页面会明确标注该数据不代表真实公司财务情况。真实接口恢复后，刷新操作会重新加载告警和公司列表。
