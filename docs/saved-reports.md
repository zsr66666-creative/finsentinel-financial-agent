# 私人研究报告

从三七互娱或科大讯飞公司页的2024FY合并财务核对保存研究报告，在“我的研究 → 研究报告”重新打开、导出JSON/Markdown或删除。标题和问题是用户备注；金额、证据与复核记录均由服务器重新读取生成。报告保留生成时快照，后续来源与复核变化不自动改写，需重新生成新报告。

报告按登录账号隔离，每账号最多200份。不接受浏览器提交金额或复核状态。不完整数据保留待复核，不展示虚构数值。PDF物理页链接仍需登录，完整文件可读不代表全文已索引。

显式迁移008_saved_research_reports，应用启动不自动建表。部署前验证备份与隔离恢复，迁移后失败只恢复旧服务配置；新增表保留。只含源码的离线包有manifest与SHA256，不包含账号、PDF或密钥。

上线后验收：保存报告；重新登录打开内容；导出两种格式；从证据打开PDF；换账号不可见；删除不影响其他收藏。服务器HTTP验收与浏览器业务验收分开。
