# Week 16 Day 5：3–5 分钟演示脚本

## 0:00–0:30 启动与边界

启动后端和前端，打开 `http://localhost:3000`。先指出页面顶部的 `DEMO / 合成数据` 或 `API ONLINE` 状态，说明演示数据不能当作真实财报结论。

## 0:30–1:20 风险总览

展示监测公司、待复核、高风险告警和证据定位统计。说明风险分布直接来自当前告警列表，避免把静态目标值当成实测结果。

## 1:20–2:10 告警与证据

打开一条告警，依次展示原始证据、指标与公式、执行轨迹。合成模式下明确说“示例页号”；真实语料模式下才解释真实来源 URL、页码和段落。

## 2:10–2:50 公司研究与数据质量

切换公司研究页面，展示指标加载、空数据和失败重试状态；再打开数据质量页面，说明质量记录来自服务端，不把合成快照描述为真实采集结果。

## 2:50–3:40 人工复核闭环

进入人工复核，演示确认、修订或驳回，并说明反馈会进入历史和回归候选。离线时明确提示不会写入服务器。

## 3:40–4:30 评测与限制

打开评测页面，展示命中数/总题数、语料版本、运行时间和代码版本。最后说明真实 LLM、容器部署和浏览器视觉验收的当前边界。

## 演示禁用事项

- 不把 synthetic fixture 当真实公司数据。
- 不把确定性适配器结果称为真实 LLM 对照。
- 不展示未核验的真实 PDF 页码作为演示证据。
- 不承诺投资收益或交易建议。
