# FinSentinel v0.1.0-rc1

## 发布范围

这是一个面向消费电子研究的证据链工作台候选版本，包含 FastAPI API、Next.js 页面、确定性财务计算、风险告警、证据展示、人工复核和评测记录。

## 已验证

- 后端测试：50 passed。
- 前端测试：10 passed。
- TypeScript 类型检查：通过。
- 前端生产构建：通过。
- GitHub Actions 配置覆盖后端和前端自动检查。

## 不应过度解读

- 默认页面是 synthetic demo；演示公司、金额、页码和证据不是实际财报结论。
- 第十四周单/双 Agent 对照使用确定性适配器，未配置真实 LLM provider。
- Podman/Docker 端到端部署和浏览器视觉验收未在所有环境完成。
- 项目不提供投资建议、交易信号或收益承诺。
