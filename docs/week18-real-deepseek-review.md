# Week 18 真实 DeepSeek 人工核验

## 评测范围

- Provider：DeepSeek `deepseek-chat`
- 数据集：Week 17 development 题集中的 10 条唯一题目
- 输出来源：用户提供的单 Agent 与双 Agent 文本
- 去重规则：两组输出包含相同的 10 个 `case_id`，因此按唯一 case 计数，不把重复输出计为新增样本。

## 人工核验结果

| 指标 | 结果 |
|---|---:|
| 唯一题数 | 10 |
| 答案正确 | 1 / 10 |
| 证据命中 | 0 / 10 |

`case-011` 的“2687.95亿元”与黄金值 `268794737612.58 CNY` 在合理四舍五入范围内一致，因此答案判为正确；但模型返回的 `evidence_ids` 为空，证据仍判为未命中。其余 9 条没有给出黄金答案对应的数据，或明确拒答，答案判为不正确。

所有 10 条模型输出的 `evidence_ids` 均为空，因此没有任何一条满足证据命中条件。HTTP/API 成功或文本返回本身不等于答案正确，也不等于证据命中。

## 限制

- 单 Agent 和双 Agent 的文本在本次粘贴结果中重复，不能据此比较两种架构的优劣，也不能宣称双 Agent 提升了质量。
- 当前结果只反映这 10 条 development 题，不代表 test 集表现。
- 后续真实运行应分别保存每个条件的完整逐 case 输出，并强制要求模型返回可核验的 `evidence_ids`。
- 用户此前暴露过 DeepSeek API key；该 key 不应写入文件或提交，建议立即撤销并重新创建。
