# 连续页口径与结构化比较验收

本轮仅增加独立实验模块，不改变线上检索、冻结评测算法或历史失败记录。

## 连续页来源

`annotate_complete_pages` 只允许调用方提供从同一 PDF 完整提取、按物理页码递增的页面。`complete` 是调用方契约，不是本函数能够自行证明的属性；不能把稀疏片段标为完整页面。缺页或不完整页中断上下文，其他报表标题终止资产负债表口径。

可复现命令（需本地私有 PDF、PYTHONPATH=backend）：

```text
python scripts/week04_contiguous_scope_check.py --pdf <PDF路径> --output data/evals/week04-contiguous-scope.json
```

脚本锁定 PDF SHA256，完整提取物理页 60–63。合并应收账款位于第 60 页，母公司应收账款位于第 63 页，母公司标题来自第 62 页。文本提取核验通过；尚未进行新页面的视觉或人工复核。未验证 OCR、多栏阅读顺序或跨其他文档的泛化能力。

## 比较契约

`compare_evidence` 只接收调用方已核实的结构化数值、公司、指标、ISO 日期、单位、合并/母公司口径和证据 ID。支持大于、小于、等于及其显式否定，使用 Decimal；公司/指标/单位/口径不同、非有限数值、缺少证据 ID、日期顺序不成立或不支持的关系返回 `needs_review`。

`supported` 仅表示给定输入支持算术判断，不证明原文抽取正确。该函数不解析自然语言，不处理期间累计口径换算，不预测未来，也不自动解决任意否定问句。缺证据预测题仍需真实端到端验收。

## 交付边界

没有修改阿里云数据库、重启网站或接入生产 API。历史专项验收结果保持原样；本轮测试不能替代独立测试集或线上验收。
