# Week 12 Day 4：性能与错误监控

## 完成内容

- 后端增加请求观测中间件，记录方法、路径、状态码和耗时。
- 每个响应增加 `X-Process-Time-Ms` 请求耗时头。
- 增加 `/api/v1/observability`，返回请求总数、错误数、错误率、平均耗时和最近 50 条请求。
- 记录标准日志，便于通过 `podman compose logs backend` 排查接口问题。

## 边界

观测数据保存在当前进程内存，服务重启后清空；它用于本地联调和基础回归，不替代生产监控系统。

## 验证

- 后端测试覆盖成功请求、404 错误、响应耗时头和观测汇总。
