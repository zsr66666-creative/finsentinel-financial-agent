# macOS 研究应用视觉改版

用户已确认：浅灰半透明侧栏替换暖茶色侧栏，柔和雾蓝/浅绿背景、蓝色选中态、系统字体、精细边框、实色阅读卡片。覆盖总览、公司详情、比较、登录和设置。保留所有业务数据和交互；不添加无效的窗口关闭按钮或模拟操作系统功能。

实现隔离于 macos.css，跟随现有主题提供浅色和深色令牌。导航与外观控件使用静态模糊，有不支持模糊、减少透明度和增强对比度的实色回退；移动端保持导航可滚动和44px触控目标。

验收：前端既有测试、TypeScript；生产构建在 ECS 执行。实际页面视觉、键盘、手机、浅深色和既有比较/检索流程仍待部署后验证。部署继续采用固定修订源码归档，避免 GitHub API 逐文件限流；构建后才切换并保留回退。
